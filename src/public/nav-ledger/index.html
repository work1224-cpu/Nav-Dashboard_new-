ⓘ   About the Metrics

Return CAGR: Annualised growth rate over the selected period for SIP and Lumpsum investments.

Rolling Returns: Calculated for rolling windows of different time periods.

CAGR =   ( End Value / Start Value )1/n − 1   ×  100
Where n = number of years · returns are annualised for periods of one year or more.
