ⓘ   About the Metrics

Calendar Year: Each year label (e.g. 2025) means the NAV as of 31 March of that year — India's financial-year end — same convention as the existing Calendar Year tile, just recalculated live from api.mfapi.in's daily history.

Rolling Return: Year-over-year change from the previous year's 31-March NAV to this year's 31-March NAV.

CAGR: Cumulative annualised growth from the scheme's very first tracked year's 31-March NAV all the way through to this year — so it grows across the row, not a single isolated year.
